# DSA in Java

A personal repository documenting my journey of learning and practicing **Data Structures and Algorithms (DSA) using Java**.

This repository contains Java programs and problem-solving exercises organized by topic, from programming fundamentals to core DSA patterns. The goal is to strengthen logical thinking, understand algorithmic patterns, and develop consistent problem-solving skills through hands-on practice.
