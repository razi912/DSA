# DSA

This repository contains Java programs written while learning **Data Structures and Algorithms (DSA)** — starting from the fundamentals (math, conditionals, patterns) and building up towards arrays, searching/sorting, and beyond.

Each program lives in its own `.java` file under `src/`, organized by topic package, and can be compiled and run independently.

## Purpose

This repo is a personal practice log for building strong DSA fundamentals in Java — one problem at a time. It's meant to track progress, reinforce concepts through repetition, and serve as a quick reference for previously solved problems.
